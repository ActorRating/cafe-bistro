# Cafe&Bistro

Modern, premium landing page for Cafe&Bistro — a Mediterranean bistro in Istanbul.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite
- Tailwind CSS
- Cormorant Garamond + Outfit typography
